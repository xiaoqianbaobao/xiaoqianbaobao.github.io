Agent Skills 大战，四家大厂同一天挤进 GitHub Trending

从 GitHub Trending 上的四类项目出发，理解 Agent Skills 为何正在从提示词升级为可打包、可验证、可分发的工作单元。
November 7, 2026

本文按 2026-11-07 的 GitHub Trending 与仓库公开信息撰写；热度、Star 数及项目状态会持续变化。

今天 GitHub Trending 前十里，有四家机构在干同一件事：给 AI 造"技能"。

Anthropic 官方仓库 18.8 万星，Google 2.3 万星，Cloudflare 拿安全审计技能冲上 6.5 万星，还有独立开发者 Matt Pocock 把 .agents 目录里的东西开源，直接堆到 31.7 万星。

四家不约而同押注同一个词：Agent Skills。

这不是又一轮"给模型写提示词"。我看了这几个仓库，真正有意思的是，这套东西想把"让 AI 怎么干活"变成一个可以打包、可以分发、可以版本化的商品。以前你是在教模型说话，现在他们在教模型干活，还打算把这套"干活手册"变成行业标准。

这一篇文章，我从今天榜单上的真实项目讲起，拆开看为什么 Agent Skills 值得你专门花一个晚上搞懂。

一、先看今天到底发生了什么#

榜单上四个项目，类型其实不太一样。

Anthropic 的 anthropics/skills，是官方把"技能"这套概念的定义和示例摊给社区。18.8 万星不是一天涨起来的，但这个信号很直接：技能这个词，官方认了，还在主动推。

Google 的 google/skills 更直白——把 Google 自己产品的调用能力包装成技能。它表面是在给开发者发福利，本质是在给 agent 生态卡位：谁想让 agent 用 Google 的东西，都得先过我这道"技能"的门。

Cloudflare 那个 security-audit-skill，6.5 万星，是让编码 agent 做多阶段安全审计，输出机器可读、能独立验证的发现。它的卖点是"让 agent 审 agent 写的代码"，直击安全这个 AI 编程的最大顾虑。

四家各打各的算盘，但都在往"技能库"这个方向堆。这说明一件事已经板上钉钉：单靠给大模型写提示词，喂不动真正的 Agent 时代了。

二、技能和提示词，为什么是两码事#

我在本地试过几个 skills 包之后，最大的感受是：提示词是临时工，技能是正式员工。

一个提示词，是你在对话里塞给模型的一段话，说完就完，换个会话就没了。它不版本化、不验收、不打包，全凭你临场发挥。

一个 skill 不是这样。它有明确的输入输出、有步骤拆解、有可以被检查的产出——比如 Cloudflare 那个审计技能，跑完会给你一份机器可读的发现清单，你可以拿去二次验证。它从"口头交代"变成了"正式录用，签了劳动合同"。

这是质变。因为一旦"怎么干活"变成可复用、可验证、可分发的模块，它就不只属于你一个人了。它能进团队、能上市场、能像应用商店那样被分发。当年 Chrome 靠扩展生态做起来，安卓靠应用商店做起来，我怀疑 Agent 生态正在走同一条路——而这条路的第一块基石，就是技能库。

三、一个 31.7 万星的重构信号#

榜单上最扎眼的一个，不是大厂，是 Matt Pocock。

他是 TypeScript 圈子里很有名气的讲师，这次不是讲一套新框架，而是直接把他平时用的 .agents 目录开源了。31.7 万星，是今天整个 Trending 里 star 数最高的几档之一。

这个细节我看了很久。他不是 OpenAI，不是 Anthropic，是个独立开发者。但他靠"分享自己教 AI 怎么干活的经验"，拿到了比多数大厂官方仓库更高的关注度。

这说明两件事。第一，技能比想象中更"值钱"——一个独立开发者把实操经验标准化、开源出来，市场的认可来得又猛又直接。第二，技能的门槛比模型低。你不需要训练一个模型，你只需要把你那一套"在 AI 面前高效干活"的方法整理成文件，就能形成资产。这对做自媒体、做内容、做工具的人来说，都是明显的信号。

四、让 Agent 审 Agent，安全这件事开始有了新玩法#

Cloudflare 那个技能是我今天看到最"实"的。

它不做花活，就是把"代码审查"这件工程师每天都要做的事，做成一个 Agent 能自动跑的多阶段流程。低风险先放，高风险直接拉到真人面前。做法看像是 LiveReview 一类产品在 Product Hunt 上打的市场，但 Cloudflare 把它做成了开源技能。

我判断这正是 Agent 落地最现实的方向：不是让 Agent 替你做所有决定，而是让 Agent 帮你把 80% 确定性强的脏活先干完，剩下 20% 需要判断的交给真人。安全审计、代码 review、数据处理，都是这样。

很多人在讨论"AI 会不会抢走程序员工作"——答案其实不在那个"抢不抢"里，而在这里：当"怎么干活"变成可共享、可复制的技能包，剩下不可替代的，是那些"怎么拆问题、怎么定标准、怎么把经验变成技能"的人。

五、普通人能从这一波里得到什么#

先泼一盆冷水，别急着把所有时间砸进去。现在的 Agent Skills 生态，还处在"标准之争"的早期，你今天学会的某个技能格式，半年后可能就不是主流。但有几件事值得现在就开始做：

第一，去把 anthropics/skills 和 google/skills 两个仓库 clone 下来，把里面定义技能的规范读一遍。不需要会写，只需要知道"技能的文件结构长什么样"。这是门槛最低、回报最确定的一步。

第二，把你自己那个"教 AI 帮你干活"的过程，第一次文档化。哪怕是"我每次都让 AI 用某个目录结构去整理周报"，把它固定成模板，就是你的第一个技能包。别管它卖不卖得出去，先把它变成可复用的东西。

第三，如果你想做内容，这条路简直为你量身定制：技能库拆解、AI 使用技巧、甚至是一个独立开发者靠开源技能冲上 Trending 的故事，都是现成的选题。

结尾，一个值得你想的问题#

我给不了你"下一个 AGI"的预测，但有一个问题想留给你琢磨：当"技能"成为 Agent 世界里的新货币，那么这套技能库的"发行权"到底该属于谁——是造模型的那几家，还是每个真正会干活的人？

这个问题没有标准答案。但它值得你今晚睡前想一遍。等你把第一个技能包写出来的时候，心里大概就有底了。
